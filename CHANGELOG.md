# Changelog

All notable changes to Wissem Home are documented in this file.

## [0.2.3] - 2026-10-01

### Changed

- Wissem UI 0.8.1: softer dark glass, and the page no longer shifts when the language menu opens.

## [0.2.2] - 2026-10-01

### Changed

- The active link of the header follows the page on the English site.
- Experience logos are no longer cropped.
- The interests orbit is animated, and stops with reduced motion.
- The password manager is listed under Studies.
- Project cards and internships show only the year, without "since" or durations.
- Wissem UI 0.8.0: deeper Liquid Glass.

### Removed

- Wissem SSO from the projects list.

## [0.2.1] - 2026-10-01

### Changed

- Portfolio cover refreshed from the deployed site.

## [0.2.0] - 2026-10-01

### Added

- English pages under `/en` with `hreflang` alternates and a bilingual sitemap.
- Ten projects with month-level dates, tags, status and category filters, and optimized local images.
- Sharing images per language, generated by `bun run images:og`.
- Valibot schema shared by the contact form and the API, a honeypot field, and end-to-end tests with accessibility checks (`bun run test:e2e`).
- One resume per language: `CV_Wissem_BADRAOUI.pdf` and `CV_Wissem_BADRAOUI_EN.pdf`.

### Changed

- The header, theme toggle, language menu, reveal animation and background come from Wissem UI.
- Interface icons use Remix only.
- The default image version in the Dockerfiles is `dev`; releases set it from the tag.

### Removed

- The `/locale/*` and `/theme/*` fallback routes and the duplicated language and theme cookies.

Releases 0.1.6 to 0.1.8 were not recorded here; see the GitHub Releases page.

## [0.1.5] - 2026-09-26

- Publish future images as `ghcr.io/wissem-industries/home`.
- Use BuildKit secrets for the private Wissem UI dependency.
- Add OCI image metadata and automate GitHub Releases after successful deploy.

[0.1.5]: https://github.com/Wissem-Industries/Wissem-Home/compare/v0.1.4...v0.1.5

The project follows [Semantic Versioning](https://semver.org/).

## [0.1.4] - 2026-09-23

### Changed

- Reworked all French and English portfolio copy into a concise, impersonal style.
- Harmonized the wording of experience, education, project, profile, and contact content.

## [0.1.3] - 2026-09-23

### Fixed

- Preserved the WissemUI card border when hovering portfolio cards.
- Replaced the conflicting hover shadow with a subtle surface change and one-pixel lift.

## [0.1.2] - 2026-09-23

### Fixed

- Serialized tagged releases so installation, checks, image publishing, and Dokploy deployment run in the correct order.
- Restored reliable automatic production deployments from release tags.

## [0.1.1] - 2026-09-23

### Fixed

- Kept animated sections visible when switching between French and English.
- Stabilized translated list identities and registered dynamically rendered reveal elements.

## [0.1.0] - 2026-09-21

### Added

- Initial public release of the rebuilt portfolio using Nuxt, WissemUI, Bun, and Biome.
- French and English content, projects, contact form, SEO, responsive layouts, and light/dark themes.
- Container publishing and Dokploy production deployment workflow.
